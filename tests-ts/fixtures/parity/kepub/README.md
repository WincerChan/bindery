# KEPUB fixed reference data

`input-*.epub` are deterministic small books used by `tests-ts/kepub-parity.test.ts`.
`reference.json` is generated by the real kepubify binary; tests never execute it or
derive the expected values from the TypeScript implementation.

## Reference tool

- kepubify **v4.0.4** (MIT), Linux 64-bit binary.
- SHA-256: `37d7628d26c5c906f607f24b36f781f306075e7073a6fe7820a751bb60431fc5`.
- Generated: 2026-10-21.
- Command: `KEPUBIFY=/path/to/kepubify node tests-ts/fixtures/parity/kepub/generate-reference.mjs`
  (fixtures themselves come from `node tests-ts/fixtures/parity/kepub/make-fixtures.mjs`).

The reference generator runs `kepubify -o <input>.kepub.epub <input>.epub`, inspects the
result with fflate, sorts members by name and writes `reference.json`.

## Normalization

Only ZIP-container differences are normalized, matching the task contract:

- member order: sorted by name;
- ZIP timestamps, compression method/bytes, extra fields and comments: ignored;
- all text-like members (`.xhtml`, `.html`, `.htm`, `.opf`, `.xml`, `.ncx`, `.css`, `.txt`,
  `.svg`) are stored verbatim as UTF-8 text, including a UTF-8 BOM where kepubify kept one;
- binary members store SHA-256 and uncompressed size.

No HTML, OPF, CSS, path or metadata normalization is applied. Every member name and
byte of text content must match. The async Worker packer is also asserted to produce the
same normalized members as the synchronous Node path.

## Coverage

`input-mixed.epub` covers Chinese/English sentence splitting, mixed punctuation,
inline nesting, links/footnote links, `br`, `pre`/`code`, `script`/`style`, `svg`,
`math`, images, tables, entities, existing `koboSpan`, existing
`book-columns`/`book-inner`, an empty chapter, malformed paragraph/div nesting,
non-UTF-8 charset declarations and a path with spaces, Chinese and `&`.

`input-titlepage.epub` covers a first-spine cover (no dummy titlepage), OPF BOM + CRLF,
EPUB 3 package metadata and cover-image detection.

`input-dummy.epub` covers the dummy-titlepage heuristic, a non-linear first spine item,
Calibre metadata removal, and the kepubify file filter (`calibre_bookmarks.txt`,
`iTunesMetadata.plist`, `.DS_STORE`, `__MACOSX`, `thumbs.db`, directory entries).

## Optional local real-library checks

These are not part of the required fixture gate and never run without explicit
environment variables. They read the library only; real books are not committed.

### kepubify parity on every library EPUB

```bash
KEPUBIFY_BIN=/path/to/kepubify \
BINDERY_PARITY_LIBRARY=/path/to/library \
pnpm vitest run tests-ts/kepub-local-parity.test.ts
```

The test copies each EPUB into a temporary directory, runs
`kepubify -o <name>.kepub.epub <name>.epub`, converts the same input through the
async Worker path, and compares every member name and byte. Without
`KEPUBIFY_BIN`, or when the library directory is missing, it reports the skip
reason and does not touch any real book.

### Staged performance benchmark

```bash
BINDERY_BENCH=1 \
BINDERY_BENCH_LIBRARY=/path/to/library \
pnpm vitest run tests-ts/kepub-bench.test.ts
```

The benchmark selects the largest EPUB, warms up, then reports median total and
per-stage times (unpack, OPF, inflate, HTML transform, native compression, ZIP
assembly) plus one synchronous run. `pnpm test` only collects the skipped
placeholder unless `BINDERY_BENCH=1` is set.
