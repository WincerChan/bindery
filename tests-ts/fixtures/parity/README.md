removed in phase 5. They are input to the existing parity assertions; no test
executes Python anymore.

## How each fixture was generated

after generation) built the same temporary TS libraries used by the parity
tests, called the Python oracle scripts, and wrote the JSON below. The oracle
scripts were also removed with the Python implementation.

## Normalization rules

Only run-dependent values are normalized:

- current ISO timestamps → `<time>` / `TIME`;
- randomly generated 32-hex book ids → `<book_id>`;
- temporary absolute paths → `<library>/<id>`;
- cover mtime query → `?v=<mtime>`;
- EPUB OPF `dcterms:modified` → `TIMESTAMP` / `__MODIFIED__`;
- ZIP container metadata and compression bytes are never compared, only member
  names, order and normalized member SHA-256 or content.

Business fields, chapters, CSS, metadata, WebAuthn signatures and row contents
are not normalized.

## Size

The whole directory is about 406 KB of file content (~572 KB on disk),
dominated by the 11 small input EPUBs (~28 KB total), the recorded data-layer
snapshots plus `alternating-replay.json` (~193 KB), the legacy reader template
script (~63 KB) and the gzipped core reference (32 KB). No output EPUB binaries
are committed.

Real-library-only references are not committed. They live in the gitignored
`.parity-local/` cache; see `scripts/parity-local.md`.
