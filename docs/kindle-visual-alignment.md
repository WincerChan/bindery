# Kindle 页面与批准原型的视觉对齐

对照来源：`docs/design/kindle/{Main,Transfer,Preview,Fonts,Connect}.dc.html` 的 HTML、内联样式及 `renderVals()`。样例只用于确认结构与尺寸，运行页面继续读取真实书库、设备、队列、方案和字体。

## 共用结构与约束

- [x] 内容原先沿用通用页面的顶部 32px 留白、1200px 容器；Kindle 页改用原型的 1280px 外框、桌面左右 32px、顶部 8px、底部 96px。连接页单独使用 1080px 外框与顶部 56px。相关选择器只匹配 Kindle 页面及其共享页头，不改变其他页面布局。
- [x] 设备栏原先把设备名称塞进状态行，未连接时仅剩状态文字。恢复左侧「状态行 → 26px/700 的 h1 → 12px mono 元信息」，右侧检测/授权/连接操作；检测中、未连接、拒绝授权及断开均保留这套结构。成功连接后的分类用量在中部显示。
- [x] 状态点、成功/危险/正文/次级文字、分隔线和进度条使用共享颜色 token；补充原型中的控件边框、浅灰文字、进度底色和警示色 token。设备预览外壳与纸色局限于预览样式。
- [x] tabs 原先上下都有边线、字重 650、垂直 padding 偏大；改为仅底部分隔线、44px 高、14px 字号、28px 间距，活动项 700 字重与 2px accent 下划线。
- [x] 新增按需使用的 UI 变体：`Chip variant="filter"`（32px 下划线文字筛选）、`Button variant="quiet-danger"`（透明危险操作）、`Button variant="icon"`（36px 图标操作）、`TextField labelHidden`（保留关联 label，仅视觉隐藏）。原有 chip 和按钮变体样式不变。
- [x] SVG 图标位于 Kindle slice；每个图标操作有明确 `aria-label`，SVG 自身 `aria-hidden`。原生输入、checkbox、select、dialog、进度条及焦点样式继续可用。
- [x] 保持中性 SSR 首屏，设备访问仍在挂载后开始；没有修改 `scripts/solid-options.ts`、条件编译兼容设置、设备订阅 memo、事务、轮询或 effect cleanup。沿用 `solid-client-rendering.md` 和 `kindle-page-regressions.md` 的约束。

- [x] 搜索框拉伸、标签占据上一行 → 240px 搜索框和视觉隐藏的关联标签，与删除和传书操作组成靠右的同一组；工具栏按原顺序自然换行。
- [x] 红色实心「删除所选」→ `btn-quiet-danger`；保留实时所选数量、禁用条件、确认流程；「从书库传书」继续使用 accent primary。
- [x] 表头原先仅有深色下边线 → 顶部 1px ink、底部 1px line，12px 灰色表头；八列均有 `scope="col"`，行间使用 line-soft。

## 明确保留的原型差异

- [x] 只展示已枚举文件的书籍/字体/其他分类及其合计，不展示设备总容量或剩余空间。
- [x] 不显示盘符。
- [x] 不显示「书库有更新」。
- [x] 不提供「压缩超大图片」。
- [x] 方案不提供上下边距控件，已有底层参数不新增 UI。
- [x] 只用真实数据；不复制样例书目、传输百分比、容量、系统字体或连接历史。未知转换大小和进度继续明确标识为未知。

## 验证与边界

SSR 结构断言覆盖五页标题层级、工具栏子元素顺序、筛选 role/pressed 状态、quiet danger class、隐藏但关联的搜索 label、空状态前的表头、侧栏字段、方案选择、型号状态、字体列、SVG 的 accessible label 与图标操作顺序。既有客户端 hydration、字体安装/删除、设备恢复/拔插、慢扫描/heartbeat、离线方案、脏草稿、队列与选择测试继续执行。生产 handler 测试通过直接 Request 调用检查实际路由，不监听端口。

最终验证结果：

- `pnpm build`：通过（客户端与 SSR）；仍有既有 `inputValidator` 弃用和 ingest 混合导入提示。
- `pnpm typecheck`：通过。
- `pnpm test`：50 个文件、986 项通过，无跳过。
- `git diff --check`：通过。
- 离线检查构建 CSS：新增共享 token、隐藏标签样式、下划线筛选、quiet danger、36px 图标按钮和 12px mono 生成 CSS 面板均已输出。

期间一次全量测试中，`tests-ts/library-production.test.ts` 的 Node 24.14.0 子进程在 `cjs_lexer::Parse` / `node:internal/modules/esm/translators` 处出现 `FATAL ERROR: v8::ToLocalChecked Empty MaybeLocal` 原生崩溃，其余 985 项通过。同一产物单独复跑该项、随后全量复跑以及最终代码的全量测试均通过；未改动书库生产测试或相关业务代码。该原生崩溃的原因尚未定位，不能据此归因于某项业务改动。

源码和 CSS 经过逐项核对；本环境按任务要求没有浏览器、网络或 socket，因此 **390px 和桌面像素效果、Windows Edge 实际字体度量、实机 USB/字体菜单尚未进行浏览器或实机验收**。SSR/Node DOM 测试不承担布局度量或像素比较。
