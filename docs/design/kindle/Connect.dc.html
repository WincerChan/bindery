连接你的 Kindle

用 USB 线连上电脑后，在浏览器里选中 Kindle 的根目录。Bindery 只读写这个目录下的 documents/、fonts/ 和 system/thumbnails/。

  1. 01
    用 USB 线连接 KindleKPW3、KO3 会作为一个磁盘出现，比如 Windows 上的 E:\
  2. 02
    点击下方按钮，选中 Kindle 磁盘的根目录根目录里能看到 documents 和 system 两个文件夹
  3. 03
    在浏览器弹窗里允许编辑浏览器重启后再次授权时会出现「每次访问都允许」，选它之后插上就能直接识别
  4. 04
    第一次连接这台设备：选择型号Bindery 会在设备上写入 .bindery/device.json，之后靠它认出是哪台 Kindle
需要 Chrome 或 Edge 桌面版
