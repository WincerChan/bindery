设备 · 未连接

把 Kindle 或 Kobo
用 USB 接上。

  1. 01用 USB 线连接设备两种设备都会作为 USB 磁盘出现，传书时保持连接。
  2. 02选择设备磁盘的根目录Kindle 能看到 documents 和 system；Kobo 能看到 .kobo。
  3. 03在浏览器弹窗里允许编辑第一次连接时确认型号、起个名字。
需要 Chrome 或 Edge 桌面版
